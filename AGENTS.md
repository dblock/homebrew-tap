# Working on Homebrew Tap

Read [CONTRIBUTING](CONTRIBUTING.md) first.

This repository is the `dblock/tap` Homebrew tap. Its formulae install prebuilt release archives of tools by @dblock, such as [fue](https://github.com/dblock/fue-rs) and [excalc](https://github.com/dblock/excalc-rs).

## Invariants

- Formulae in `Formula/` are generated by `bin/update-formula` from each tool's latest GitHub Release; never edit them by hand. Change the template or the `FORMULAE` list in `lib/formula_updater.rb`.
- Every archive needs a published `.sha256` file; never compute or hardcode checksums yourself.
- Generated formulae must pass `brew audit --strict`, `brew install`, and `brew test`; do not weaken those checks.
- The Update Formulae workflow commits directly to `master` with the workflow token. Do not add secrets or personal access tokens; it only reads public releases.
- Use `example.com` addresses rather than real people's e-mail in tests.

## Validation

```sh
bundle exec ruby -Ilib test/formula_updater_test.rb
bin/test-formulae
rumdl check .
```

Branch as `dblock/<topic>`, keep one commit per pull request, use rebase merges only, include an AI co-author trailer in AI-assisted commits, and disclose AI authorship in pull request descriptions and comments.
